Hardware

Hardware we build
and test on.

Rytmi is developed and tested on two machines built from off-the-shelf PC parts: a desktop Intel processor, a retail motherboard, standard non-ECC memory, NVMe and SATA solid-state drives, and a Blackmagic DeckLink card. They run Ubuntu 24.04 LTS, with Ubuntu’s own kernel and FFmpeg packages. There is no appliance, and no hardware of our own design.

That is deliberate. Every part in the tables below is a standard product sold through ordinary retail channels, so a failed part can be replaced with one bought from a retailer. And the two machines come from different hardware generations, with different processors, chipsets and motherboard makers, so a result on one can be checked on the other. Because they differ in several ways at once, a difference between them does not point to any one part.

This is not a certified configuration or a minimum specification. The two machines are development benches running a test schedule, and this page says nothing about hardware we have not tried. Everything on this page is as of 29 Sep 2026 unless it carries another date.

What each unit does

As of 29 Sep 2026.

  • The first unit plays one channel, 1920×1080 progressive at 50 frames a second (1080p50), on one of its card’s SDI outputs. Of the card’s four outputs, three work; the fourth is the known fault below.
  • The second unit plays four channels, each 1080p50, one on each SDI output. On 27 Sep 2026, the last time its cabling was recorded, none of the four outputs had a cable attached; only the reference input did. So what it played then was counted inside the machine, by the engine and the card, and nothing downstream watched it.
  • Reference. On 27 Sep 2026 both units took a reference from the sync generator listed under test kit. With the generator at 1080i50 their cards did not lock their 1080p50 outputs; at 720p50 they locked. We switched the generator off the same day, and both units read free-running on 29 Sep 2026. What locking showed, and what it did not cover, is in the archive: genlock, 27 September 2026.

Known fault

As of 29 Sep 2026
  • The first unit’s fourth SDI output does not work. It has not worked since the card was fitted, in May 2026. The card’s driver still lists all four outputs, and none of our software on the machine has detected the fault.
  • Fix underway. A replacement card is coming back to us from a warranty return. It takes this card’s place, and this card then goes back under warranty itself. Until the swap, the first unit uses three of the four outputs.

The FFmpeg versions are the ones the engine uses: on the first unit, read from the libraries the running engine has loaded; on the second, from the libraries its engine binary resolves to on that machine. Other Ubuntu packages, which this table does not list, are not all at the same revision on the two units.

As of 29 Sep 2026, both units had run the same Rytmi source since 18 Sep 2026, each built on its own machine. Setting a machine up for Rytmi also changes some operating-system settings; those are part of how we install Rytmi, and are not listed here.
